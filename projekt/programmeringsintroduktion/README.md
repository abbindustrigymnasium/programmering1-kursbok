# Projekt: Programmeringsintroduktion

## Syfte

I det här projektet lär du dig grunderna i webbprogrammering med de tre språk som hela webben bygger på: HTML för struktur, CSS för utseende och JavaScript för logik. Du lär dig också att få JavaScript att styra sidan via DOM. Allt detta använder du senare i kursen, bland annat i webbappen i temperaturprojektet.

## Koppling till kursen

**Kriterier i vanliga ord**

- Du visar att du kan förklara hur språken fungerar och vad de används till (kriteriet om programmerbara system, programspråk och programmeringsparadigm).
- Du formulerar och löser programmeringsproblem på egen hand (kriteriet om att formulera och lösa problem).

**Centralt innehåll:** programmering i textbaserade språk, grundläggande kontrollstrukturer, skapande av enkla program, användning av verktyg, felsökning, gränssnitt mot användaren och datorns möjligheter och begränsningar.

## Vad du ska göra

- Sätta upp VS Code och GitHub och spara dina övningar i GitHub Classroom.
- Bygga webbsidor med HTML: rubriker, text, länkar, bilder, listor, formulär och layout.
- Styla sidorna med CSS: selektorer, färger, boxmodellen, typsnitt, positionering och Flexbox.
- Lösa övningsuppgifter i JavaScript: variabler, villkor, loopar, funktioner, objekt och arrayer.
- Koppla ihop JavaScript med din webbsida via DOM, så att sidan reagerar när användaren klickar eller skriver.

## Krav och leverabler

- Du gör övningarna löpande och pushar dem till GitHub.
- Du bygger en egen enkel webbsida med flera sidor och ger den en layout med CSS.
- Projektet avslutas med ett prov i HTML, CSS och JavaScript.

## Bedömning

Projektet bedöms genom provet. Där visar du hur väl du kan förklara hur språken fungerar och vad de används till, och hur du löser programmeringsuppgifter på egen hand. Det bästa sättet att förbereda dig är att göra övningarna löpande.

## Tips

- Pusha efter varje lektion, så har du alltid en säker kopia.
- Testa din kod ofta. Det är lättare att hitta ett fel om du bara har ändrat lite.
- Förbered dig inför provet genom att förklara koden högt, inte bara genom att läsa den.
- Öppna utvecklarverktygen med F12 så fort något inte fungerar.
